# Data Dictionary — OULAD (Open University Learning Analytics Dataset)

## Overview
This project uses the Open University Learning Analytics Dataset (OULAD). 
It contains data about students, their interactions with the Virtual Learning Environment (VLE), and their final results.

## Tables Description
- **courses.csv**: Information about the courses (code, length, etc.)
- **assessments.csv**: Information about assessments (type, weight, date).
- **vle.csv**: Information about the Virtual Learning Environment (VLE) materials.
- **studentInfo.csv**: Demographic and final result information for each student.
- **studentRegistration.csv**: Registration and unregistration dates.
- **studentAssessment.csv**: Scores for each assessment per student.
- **studentVle.csv**: Clickstream data (daily clicks on VLE) for each student.
